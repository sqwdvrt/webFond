# Приёмка production — исправления аудита

17 ноября 2026. До деплоя текущего кода проверки ниже не считаются пройденными.
Локальные тесты и ручная приёмка production — разные доказательства.

| Сценарий | Статус | Что записать после проверки |
|---|---|---|
| Выпуск и миграция согласий | Не выполнено | SHA, миграция, T0 |
| Контактное обращение | Не выполнено | Тестовый ID, evidence, появление в админке, факт ответа |
| Разовая оплата | Не выполнено | Разрешённая сумма, дата, ID, способ, SUCCEEDED/paidAt |
| Возврат на сайт и webhook | Не выполнено | Совпадение локального ID и подтверждённого статуса |
| Доставка чека | Не выполнено | Подтверждение владельцем тестового адреса |
| Отмена оплаты | Не выполнено | Результат отдельной незавершённой попытки |
| QR четырёх банков | Не выполнено | Приложение/устройство, получатель/счёт; без перевода |
| Cleanup scheduler | Не подтверждён | Два успешных последовательных запуска |
| Reconcile scheduler | Не подтверждён | Свежий heartbeat, результат job |
| Оповещения о сбое/восстановлении | Не настроены в рамках работы | Канал, ответственный, тест на стенде |
| Backup и восстановление | Не проверены | Ссылка на безопасную запись в журнале восстановления |

Тестовую оплату выполняет владелец с заранее согласованной суммой. Не отправлять
реальные письма без разрешённого тестового адреса. Не подделывать webhook успешной
оплаты. В журнал не включать секреты, данные карты или полный email.

Фонд сообщил, что география помощи, сроки ответа и часы связи пока не определены.
Нейтральные формулировки сохранены. Наполнение проектами/отчётами/новостями отложено.
