# Проверка удобства — 18 ноября 2026

## Вывод о дизайне

Полный редизайн публичного сайта не требуется. Сохранены зелёный акцент,
светлый фон, логотип, существующие шрифты и порядок основных разделов.
Исправления направлены на путь к действию, ясность банковских счетов,
оформление формы и навигацию по длинным документам.

Визуальная оценка выполнена по живому сайту и локальной production-сборке,
а не только по исходникам. Изменения приложения на production в этой работе
не публиковались. Тестовые данные и учётная запись админки использовались
только на отдельной локальной PostgreSQL `webfond_usability_20261118_test`.

## Защищённая часть — локальная проверка

Пройдены все девять разделов: обзор, уведомления, письма, проекты, новости,
документы, реквизиты, пожертвования, изменения. Отдельно открыты новые и
редактируемые проект/новость/документ, карточка обращения, его статус/заметка,
история, ответ по email; действия отправки письма, публикации и оплаты не выполнялись.

Проверены видимые подписи фильтров, статусов, таблиц, предпросмотра и публикации.
На телефоне просмотрены очередь писем и горизонтальное меню: документ не выходит
за ширину 360 px, таблица прокручивается внутри своего контейнера.

Отдельная рекомендация для следующего небольшого этапа: дополнить мобильную
навигацию админки явным выбором раздела. Сейчас часть девяти вкладок доступна
горизонтальной прокруткой и не сразу видна. Рабочий процесс админки в этом
публичном UX-изменении не перестраивался.

## Конкретные изменения

1. Compact-вариант PageHero применяется к /help, /contacts, /requisites.
   Сокращены отступы перед рабочим содержимым; главная/информационные страницы
   не получили глобального уменьшения типографики.
2. Быстрые переходы используют обычные ссылки и устойчивые якоря с отступом
   под закреплённую шапку. Не скрывают контент вкладками и не требуют JS для перехода.
3. QR-счёт явно назван после выбора. Его копирование находится до длинной таблицы,
   подтверждение озвучивается через role=status и называет банк. Общая таблица
   имеет собственный заголовок и кнопку. Исходные счета, QR и банковские данные не изменены.
4. Контактная форма сообщает об обязательных полях. Предупреждение стоит у поля
   сообщения и связано с ним. Невалидные ссылки aria-describedby на отсутствующие
   ошибки имени/email устранены. Исправлена специфичность CSS ошибки/успеха.
5. Флажки согласия имеют размер 18 px; текст контактного согласия выровнен сеткой
   с зазором. Ловушки «Сайт» по-прежнему скрыты от диктора и исключены из Tab.
6. Оглавления юридических страниц раскрываются по запросу и не занимают весь
   первый экран телефона. Заголовок выбранного раздела получает фокус при переходе.

## Проверки

- `npm run verify`: 1575 успешных тестов; 15 DB-тестов основного набора пропущены;
  lint, TypeScript, Prisma validate, production build и diff check прошли.
- Chromium: 18 успешных сценариев, desktop 1440×1000 и mobile 360×800.
  Включены новые проверки всех четырёх оглавлений, фокуса/отступа их целей и
  перехода со страницы помощи прямо к банковскому переводу.
- Ручной просмотр: desktop 1280×900 и mobile 360×800, верхние и нижние блоки,
  выбранные QR, формы, мобильное меню, карточки/редакторы локальной админки.
- Регрессии: копирование всех четырёх счетов, отказ Clipboard API, скрытая
  ловушка, сохранение введённых данных, соответствие ссылок описаний реальным элементам.
- Независимая рецензия: существенных регрессий и нарушений согласованной задачи нет.
