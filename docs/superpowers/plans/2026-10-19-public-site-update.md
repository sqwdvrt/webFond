# Обновление публичного сайта

План согласован пользователем в чате 19 октября 2026 года. Реализация в текущем стиле, без вымышленных фотографий, географии, сроков ответа и ролей телефонов.

- [x] Контакты: единый список опубликованных телефонов в siteConfig; форма первой в DOM, точный якорь, компактные контакты сбоку; email явно нужен для ответа.
- [x] Обращение: прямая ссылка на форму, инструкция соответствует обязательному email; отдельный FAQ заявителя без неподтверждённых обещаний.
- [x] Пожертвование: форма онлайн основная; банковский перевод в details (закрыт при онлайн-оплате, открыт при отключении); реквизиты доступны вне details; FAQ донора на /help#donation-faq. Выбор проекта и платёжная логика сохраняются.
- [x] Главная: содержательный H1, компактный знак только на широких экранах (рамка возвращена по последующему замечанию пользователя); направления → опубликованные проекты/отчёты → помощь → краткие сведения и документы. Пустые коллекции скрыты, ошибки загрузки отличимы от пустых данных.
- [x] Проверки: ссылки и якорь формы, отдельные FAQ, сворачивание банковского перевода и fallback, выбор проекта, условные коллекции; существующие тесты форм; lint, typecheck, build; мобильный и широкий браузерный просмотр.

Фактическое наполнение (команда, фотографии, отчёты, география, сроки, назначение телефонов) требует материалов фонда и не подменяется шаблонным содержимым. Production deploy не входит в этот выпуск.

## Результат проверки

- Полный Vitest: 1458 passed, 12 skipped (опциональные интеграционные проверки), 0 failed.
- ESLint, TypeScript и production build завершились успешно.
- Независимое ревью изменений: замечаний нет.
- Браузер: главный экран на 1280 и 390 px; переход к форме с /need-help и прямым URL; форма под закреплённой шапкой; контакты в двух колонках на 1280 px; банковский QR на 360 px без горизонтальной прокрутки. Доступность онлайн-оплаты и выбор проекта проверены автоматическими тестами; живые платежи и отправка сообщений не выполнялись.
