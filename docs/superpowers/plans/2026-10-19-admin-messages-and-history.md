- [x] Общий верхний отступ, размещение метрик, адаптивные фильтры без обрезания текста.
- [x] В обзоре не более 5 действий; отдельный защищённый /admin/changes с полной историей по 25 событий на страницу, стабильный порядок createdAt/id.
- [x] Папки INBOX/ARCHIVE/TRASH отделены от NEW/IN_PROGRESS/CLOSED/SPAM. Аддитивная миграция сохраняет все письма во входящих.
- [x] Выбор текущей страницы (до 25 писем), архив/корзина/возврат во входящие. Без физического удаления. Единая транзакция проверяет версии updatedAt и исходную папку всех записей; конфликт откатывает всю группу. Аудит содержит только идентификаторы и папки.
- [x] Защищённые server actions: авторизация до обработки данных, строгая валидация, безопасный returnTo, ошибки без приватных подробностей, revalidate списков/обзора/журнала/деталей.

Первичный браузерный просмотр обзора и списка выполнен; повторная проверка интерфейса заблокирована политикой браузерного инструмента.

Production не изменяется. Миграция локальной БД допустима после проверки localhost. На рабочем сайте новую миграцию нужно применить до обновления приложения; для отката требуется совместимый Prisma Client, способный прочитать CONTACT_FOLDER_CHANGED. Добавленное поле и события при откате не удаляются.


## Проверка

- Unit/component проверки охватывают ограничение 5 событий, пагинацию полного журнала, авторизацию, валидацию выбора и возвращаемых адресов, передачу выбранных checkbox/intent, папки, optimistic concurrency, безопасные ссылки на объекты.
- Все 6 PostgreSQL integration tests прошли в случайной изолированной схеме базы foundation_payments_test, включая реальный rollback группы, архив → корзина → восстановление и сохранение рабочего статуса. Схема удалена suite.
- Миграция применена только к проверенной localhost БД. Две временные локальные QA-записи удалены после проверки. Production не изменялся.
- Независимое ревью выявило отсутствие идентификации объекта в полном журнале; исправлено добавлением ссылки и ID. Для ссылок используются пакетные запросы по типу сущности.
- Повторная визуальная проверка через браузер ограничена политикой инструмента; полного браузерного прогона массовых действий не было. Отправка формы проверена компонентным тестом, перемещение/откат проверены на PostgreSQL.
