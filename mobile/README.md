# Проверочный мобильный клиент

Этап 0, не финальный интерфейс. Пять вкладок, поле почты без отправки, внешние ссылки на сайт и проверочный PDF W3C. Реальные аккаунты и платежи не создаются.

Из каталога `mobile`:

```sh
npm ci
npm run dev -- --port 5194 --strictPort
npm run build
npm run lint
npx playwright install chromium
npm test
npm run sync
```

Нативные исходники уже созданы. Повторно выполнять `cap add` не нужно. После установки Xcode/Android SDK:

```sh
npm run ios
npm run android
```

Проект iOS: `ios/App/App.xcodeproj`, схема `App`; Android: `android/`, задача `:app:assembleDebug`. Команды сборки выполняются из соответствующей директории. Реальная нативная сборка на этапе 0 не выполнена из-за отсутствующих SDK.

Версии, блокеры, правила платежей и хранения токенов: `../docs/mobile/decisions.md`. При изменении интерфейса сначала `npm run sync`, затем нативная сборка. Идентификатор приложения предварительный, signing и production-доступы не настроены. Локальные файлы SDK, сертификаты, keystore и секреты не коммитить.
